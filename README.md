# HerbCraft — мод для Minecraft (Fabric 1.20.1)

Мод добавляет пять разновидностей «особенной травы», которые можно найти в мире, вырастить на грядке, собрать, скрутить и использовать. Также есть котел для приготовления жидкости и электронные сигареты.

## Что добавлено

**5 видов травы:** зелёная, золотая, синяя, фиолетовая, радужная. У каждого вида свой цвет и свой эффект:
| Вид | Эффект скрутки |
|---|---|
| Зелёная | Регенерация |
| Золотая | Скорость II |
| Синяя | Подводное дыхание |
| Фиолетовая | Ночное зрение |
| Радужная | Удача II |

Дикие кусты травы спавнятся в оверворде. Сломанный куст роняет высушенную траву — она же служит семенами.

**Скрутки:** 2 травы + 1 бумага → скрутка. При использовании даёт эффект, частицы дыма и звук.

**Жидкость для вэйпа:** поставьте полный котел воды и нажмите ПКМ высушенной травой по котлу — получите жидкость соответствующего вида.

**Электронная сигарета:** крафтится из жидкости + железный слиток + стеклянная панель + редстоун. Даёт 10 затяжек, эффект в два раза дольше, чем у скрутки. Заправка: держите вэйп в левой руке и жмите ПКМ жидкостью (до 10 зарядов).

## Сборка

Нужен JDK 17 (уже установлен через winget: `EclipseAdoptium.Temurin.17.JDK`).

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.21.9-hotspot'
.\gradlew.bat build
```

Готовый мод: `build\libs\herbcraft-1.0.0.jar`.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft 1.20.1.
2. Поместите `fabric-api` и `herbcraft-1.0.0.jar` в папку `mods`.
3. Запустите Minecraft.

## Генерация ассетов

Модели, текстуры, крафты и лут-таблицы создаются скриптом:

```powershell
powershell -ExecutionPolicy Bypass -File tools\generate_assets.ps1
```

## Структура

- `src/main/java/com/herbcraft/` — основной код
- `src/main/resources/assets/herbcraft/` — модели, текстуры, язык
- `src/main/resources/data/herbcraft/` — крафты и лут-таблицы
- `tools/generate_assets.ps1` — генератор ассетов
